A blank file becomes a page

Create index.html, type the markup, and the preview answers back on the same screen. No server, no tab-switching.

Start in the Owlet workspace.

  <h1>Hello, Owlet</h1>
  <p>My first page, live.</p>
</main>

The console catches what breaks

A TypeError names the file and the line that failed. Fix the code, and the red clears on the next run.

Toggle the panel with Ctrl+J — details in the docs.

const price = cart.total;
console.log(price);
// TypeError: Cannot read 'total' of undefined

One page, three widths

The preview frame switches desktop, tablet and phone without leaving the project. The nav that fit at noon still has to fit at phone width.

More on preview presets in the docs.

.nav {
  display: flex;
  gap: 24px;
}

Markup and styles, in one project

Open index.html and style.css as tabs in the same workspace. The class name you type in the markup is the one you style, and the preview shows both at once.

Why Owlet

Change the way you work

01

No install needed

Open the page and start typing. There is no package manager, no build step and no account to create.

02

Your code stays on your device

Your project lives in the browser on your machine. Owlet does not send your files to a server.

03

Learn from readable code

The whole project is plain HTML, CSS and JavaScript, so you can read it, change it and learn from it.

Capabilities

See what Owlet can do

Six things that work today. Hover or focus a tile to see it move — planned features are listed separately below.

  • Multi-file workspace

    One project holds your HTML, CSS, JS and assets — folders nest and expand.

    index.html style.css app.js assets/ logo.svgfonts.css

  • Live preview + devices

    Desktop, tablet and phone frames — one click each.

  • Console with detail

    Errors name the file and line — inspect them in place.

    TypeError: null (app.js:3) btn.addEventListener("click", send);btn is null — check the selector

  • Tabs for every file

    Open several files as tabs, switch between them, and see the whole project in the live preview.

  • Light and dark themes

    One toggle flips the whole workspace.

  • Works offline

    A service worker keeps Owlet opening without a connection — after the first load.

      How to contribute

      1. Fork

        Create your own copy of the repository on GitHub.

      2. Clone

        Download it to your computer.

        git clone https://github.com/BrixoByte/Owlet.git

      3. Change something

        No build step. Open index.html in your browser and start editing.

      4. Open a pull request

        Describe what you changed and why. A maintainer will review it.
